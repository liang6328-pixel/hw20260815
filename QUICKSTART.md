# Quick Start 🚀

Get the Mock Test Generator running in 2 minutes!

## Step 1: Install

```bash
npm install
```

## Step 2: Run

```bash
npm run dev
```

## Step 3: Open Browser

Navigate to: **http://localhost:5173**

---

## What You'll See

A modern dashboard with:
- 📷 Camera capture button
- 📁 File import button  
- Extracted questions display
- Question selection panel
- Test summary stats
- Export options

## Try the Demo

1. **Click "Camera" or "File Import"**
   - Demo mode provides sample questions automatically

2. **Review the extracted text**
   - 5 sample questions appear in the extracted canvas
   - Edit if needed with the "Edit" button

3. **Select a question**
   - Click any question in the "Select a Question" panel
   - It highlights in blue

4. **Generate similar questions**
   - Click "Generate Similar Questions"
   - In ~2 seconds, 5 new questions appear

5. **Review and export**
   - Edit questions in the modal
   - Select export format (DOCX, PDF, TXT, JSON)
   - Click "Export Now" to download
